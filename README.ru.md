# BackloGame

Portable-приложение для игрового бэклога: что хочется пройти, что уже в процессе
и что завершено. Избранное — постоянная коллекция игр, которые хочется оставить.

[Скачать для Windows](https://github.com/w4rd3ll/BackloGame/releases/latest) ·
[English](README.md) · [Сообщить об ошибке](https://github.com/w4rd3ll/BackloGame/issues)

![BackloGame library](docs/screenshots/library.jpg)

Демонстрационная библиотека; статусы приведены для примера. В скачанной версии игр нет.

## Запуск

1. В Releases скачайте `BackloGame-0.2.0-windows-x64-portable.zip`.
2. Если Windows блокирует запуск, откройте свойства ZIP, отметьте **Разблокировать**
   и распакуйте заново. Распакуйте весь архив в обычную локальную папку с правом записи.
3. Запустите `BackloGame.exe`; папку `_internal` оставьте рядом.

Установка самого BackloGame и Python не требуется. Нужен системный **Microsoft
WebView2 Evergreen Runtime**. Если его нет, установите компонент с
[сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

Библиотека в скачанной версии пустая. По умолчанию интерфейс английский.
Русский включается в **Settings → General → Interface language → Русский**.

## Возможности

- Поиск игр в Steam, Wikipedia и Metacritic; ручное добавление.
- Импорт публичной библиотеки Steam и профиля HLTB либо CSV с просмотром совпадений.
- Даты прохождения; отдельная сортировка и вид для каждой категории.
- Восемь цветовых тем и обновления из настроек с одной предыдущей копией программы.
- Статусы прохождения, избранное, свои категории и платформы.
- Карточки, список и компактный список с миниатюрами.
- Фильтры и сортировка, включая даты; ручной порядок перетаскиванием.
- Комментарии, теги, приоритеты; несколько серий через `;`.
- Сохранение обложек, выбор области миниатюры и обновление Steam-обложек.
- Массовое редактирование и сворачиваемые боковые панели.
- Полные резервные копии и восстановление; хранится не более **10** ZIP-копий.

Для поиска нужен Интернет. Сохранённые записи, заметки и скачанные обложки
доступны локально. Программа пока не запускает игры и не синхронизирует аккаунты.

## База и обновление

Папка `data` создаётся рядом с EXE при первом запуске. В ней база, обложки,
настройки, резервные копии и профиль окна. Для переноса закройте приложение
и скопируйте всю его папку. Обновления доступны в **Настройки → Обновления**.
Версию 0.1.0 сначала нужно обновить вручную. Для ручного обновления заменяйте EXE и `_internal`,
**сохраняя свою папку `data`**. Не запускайте программу прямо из архива.

## Разработка

Проверенная среда: Windows 11 x64, Python 3.14 x64 и системный WebView2.
`Setup.cmd` устанавливает зависимости в `.venv`, `Run.cmd` запускает исходники.
`Build-Release.cmd` собирает соседнюю папку `BackloGame-Release`.
Команда `.venv/Scripts/python.exe tools/package_release.py` делает ZIP и контрольную
сумму в `dist`, исключая всю папку `data`. Личная папка сборкой не затрагивается.

Windows-часть запуска отделена от общей логики. Linux-версия пока не собрана
и не проверена. Подробнее о тестах и архитектуре — в [английском README](README.md).

Сведения о сторонних компонентах: [THIRD_PARTY](docs/THIRD_PARTY.md).
