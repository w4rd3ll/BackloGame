# Third-party components

BackloGame bundles Python, pywebview, pythonnet, CLR Loader, Bottle, proxy_tools,
typing_extensions, cffi and Pillow. Their own license terms apply; license files are
retained in the package. Microsoft WebView2 Evergreen is a system prerequisite
and is not bundled with BackloGame.

Microsoft WebView2 distribution documentation:
https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution

The RuTracker resource button uses the official site's favicon:
https://rutracker.org/favicon.ico
Application artwork was generated specifically for this project.
Game artwork and catalog descriptions belong to their respective owners.

The public package contains no user game library or game covers.
